# Context-Menu-Manager
Context Menu Manager for Windows to get rid of the useless options. Built using Visual Studio and WPF

# Features
- Dynamic Dark and Light theme
- Easy Backups and restores
- Intuitive UI
- Disable and restore Context Menu Items

# Backups

Backups are made at ~/Documents/ContextMenuManager for easy access. Their file name is `backup_{targetName}_[option]` where `targetName` is `all`, `directory` or `drive` and `option` is the Key name (eg: 7-zip).

# Restores

There is a built in Restore tab where you can restore easily. Works the same way as Backups.

# How to use

- To Disable: Select the item you want to disable in the Manage tab and click Disable.
- To Restore: Select the itme you want to restore in the Restore tab and click Restore.

# How to install

Download the latest version and extract it somewhere then double click the executable.

# Warning

Use this application at your own risk since it modifies Registry keys and files.
